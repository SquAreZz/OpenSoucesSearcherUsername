Этот бот предоставляет удобный интерфейс для мощного инструмента OSINT — Sherlock. Вы можете искать юзернеймы прямо в Telegram, получать отчеты в виде файлов и использовать инлайн-режим для быстрого поиска в любом чате.

## 🌐 Веб-версия (GitHub Pages)

В репозитории есть полноценная **статичная веб-версия** этого бота — работает прямо в браузере, без сервера и без Python, и готова к публикации на **GitHub Pages**.

**Как включить:** `Settings → Pages → Source: Deploy from a branch → Branch: main / (root)`. После этого сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/OpenSoucesSearcherUsername/`.

Что умеет веб-версия:

*   **🔗 Быстрый режим** — мгновенно строит прямые ссылки на профиль по базе из ~480 сайтов (та же база, что использует Sherlock), точно так же валидируя юзернейм (`3-30` символов, `a-zA-Z0-9._-`), как это делает `bot.py`.
*   **🧪 Экспериментальная проверка** — пытается определить, существует ли аккаунт, повторяя логику детекции Sherlock (`status_code` / `message` / `response_url`) прямо в браузере. Поскольку GitHub Pages — статический хостинг без бэкенда, а большинство сайтов не разрешают CORS-запросы из браузера, проверка идёт через публичный CORS-прокси (`allorigins.win`). Это экспериментальный режим: возможны ложные срабатывания, а сам прокси может быть медленным или временно недоступен.
*   **💾 Кэш и отчёт** — результаты сохраняются в `localStorage` браузера (аналог файлового кэша `bot_results/` у бота), отчёт можно скачать как `.txt`-файл со списком ссылок — так же, как бот присылает документ в Telegram.
*   Фильтрация по названию сайта и по статусу, переключатель показа сайтов 18+, поддержка ссылки вида `?u=username` для шаринга результата.

Файлы веб-версии: `index.html`, `assets/css/style.css`, `assets/js/app.js`, `assets/js/sites.json` — никаких зависимостей и сборки, чистые HTML/CSS/JS.

> ⚠️ Используйте инструмент только легально — для проверки собственных аккаунтов или в рамках правомерного OSINT-исследования.

## ✨ Ключевые функции

*   **Поиск по команде:** Используйте команду `/search <юзернейм>` для полного анализа.
*   **Инлайн-режим:** Вводите `@имя_бота <юзернейм>` в любом чате для быстрого поиска по кэшу.
*   **Кэширование результатов:** Бот сохраняет результаты поиска, чтобы не тратить время на повторные запросы.
*   **Безопасность:** Встроенная проверка на ввод вредоносных команд для защиты сервера.
*   **Удобные отчеты:** Результаты отправляются в виде `.txt` файла со списком найденных ссылок.
*   **Простое развертывание:** Готовый `Dockerfile` для быстрой и изолированной установки.

## ⚙️ Требования

Перед установкой бота убедитесь, что у вас есть все необходимое:

1.  **Python 3.9+**
2.  **Git**
3.  **Токен Telegram-бота:** Получите его у [@BotFather](https://t.me/BotFather).
4.  **Установленный Sherlock Project:**

> ⚠️ **Это обязательный шаг!** Бот является оберткой для Sherlock и не будет работать без него. Установите Sherlock, следуя **официальным инструкциям** из их репозитория:
> ### [https://github.com/sherlock-project/sherlock#installation](https://github.com/sherlock-project/sherlock#installation)

## 🚀 Установка и настройка

Выполните эти шаги, чтобы запустить бота на вашем сервере.

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/cat228608/OpenSoucesSearcherUsername.git
cd OpenSoucesSearcherUsername
```

**2. Создайте виртуальное окружение и установите зависимости**

Рекомендуется использовать виртуальное окружение, чтобы изолировать зависимости проекта.

```bash
# Создаем окружение
python -m venv venv

# Активируем его (Linux/macOS)
source venv/bin/activate

# Активируем его (Windows)
# venv\Scripts\activate
```

выполните установку библиотеки pip
```
aiogram==2.20
```

**3. Настройте токен бота**

Безопаснее всего хранить токен в переменных окружения.

```bash
# TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
```

**4. Включите инлайн-режим у BotFather**

*   Откройте диалог с [@BotFather](https://t.me/BotFather).
*   Отправьте команду `/setinline`.
*   Выберите вашего бота.
*   Введите текст-подсказку, например, `Введите юзернейм для поиска...`.

## ▶️ Запуск бота

После установки и настройки запустите бота командой:

```bash
python bot.py
```

Вы должны увидеть в консоли сообщение `INFO:root:Бот запускается...`.

## 🤖 Использование

### Команда `/search`

Отправьте боту личное сообщение для полного поиска и получения файла с отчетом.

` /search social_network `

Бот начнет поиск и по завершении пришлет `.txt` файл.

### Инлайн-режим

В любом чате (или в личной переписке с ботом) введите имя пользователя вашего бота и через пробел — юзернейм.

` @имя_вашего_бота social_network `

*   **Если юзернейм есть в кэше:** Бот предложит отправить краткий отчет (до 15 ссылок) прямо в чат.
*   **Если юзернейма нет в кэше:** Бот предложит нажать, чтобы сформировать и отправить команду `/search` для полного анализа.

## 🐳 Docker

Для простого и надежного развертывания вы можете использовать Docker.

**1. Соберите Docker-образ**

```bash
docker build -t sherlock-tg-bot .
```

**2. Запустите контейнер**

Не забудьте передать токен вашего бота через переменную окружения.

```bash
docker run -d --restart unless-stopped -e TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ" --name sherlock-bot sherlock-tg-bot
```
